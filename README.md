\# Mahasuvi Dictionary



A language documentation dataset for \*\*Mahasuvi\*\* (also known as Mahasu Pahari), a language spoken in the hill regions around Shimla, Himachal Pradesh, India.



\## About the language



Mahasuvi is spoken across villages in the hills surrounding Shimla. Like many regional languages of the Himalayan belt, it has a strong oral tradition, folk songs, greetings, and everyday hospitality customs, but limited formal documentation. This project aims to change that by building an accessible, structured record of the language: words, pronunciations, and visual context, contributed and verified by native speakers.



\## What's in this repository



\- \*\*`mahasuvi.csv`\*\* — the core wordlist: entries with their meanings and related metadata

\- \*\*Audio recordings\*\* — native pronunciations for wordlist entries, so the sounds of the language aren't lost to transliteration alone

\- \*\*Images\*\* — visual references tied to dictionary entries, useful for words describing objects, places, or customs that benefit from a picture



\## Why this exists



Mahasuvi, like many minority and regional languages, doesn't have the institutional resources that bigger languages do; no large-scale dictionaries, no standard orthography taught in schools, mostly passed down orally between generations. This dataset is an attempt at preserving it in a form that's usable by linguists, researchers, language learners, and the community itself, for future generations.



\## Project



This dataset is part of the \*\*Mahasuvi Living Dictionaries\*\* project, an ongoing effort to document and archive the Mahasuvi language.
